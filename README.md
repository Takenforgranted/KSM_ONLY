# KSM_ONLY 🎌

用 Python + Pillow 制作的动画小项目：**邦多利（BanG Dream!）十二个乐团的团徽，绕着中间的ksm大头照匀速转圈**，最终输出一张可以无限循环播放的 GIF 动图。

## 效果预览

下面就是程序跑出来的成品（直接在本仓库里就能看到）：

![bandori_gif](bandori_gif.gif)

- 中间：**户山香橙**的 400×400 大头照（`ksm.jpg`）
- 周围：12 个乐团团徽（Poppin'Party、Afterglow、Roselia、MyGO!!!!、Ave Mujica……）绕成一圈匀速旋转
- 循环：动画首尾帧正好衔接，**播放到最后一帧再回到第一帧时完全无缝**，看不出任何跳变

## 动画原理（一看就懂）

整个 GIF 由 72 张静止的图片（帧）连播而成，原理就像翻页小人书：

```text
第 0 帧:  logo 们分别停在   0°,  30°,  60°, ... 330°  的位置
第 1 帧:  所有 logo 整体顺时针挪 5°，变成   5°,  35°,  65°, ... 335°
第 2 帧:  再挪 5°，变成  10°,  40°,  70°, ... 340°
   ...
第 71 帧: 355°, 385°(=25°), ...（超过 360° 就减去 360°）
第 72 帧: 正好等于第 0 帧 → 无缝接回开头，无限循环 ✅
```

每个 logo 的位置用中学数学的**圆的参数方程**计算：

```text
x = 圆心x + 半径 × cos(角度)      ← cos 管"横向"
y = 圆心y + 半径 × sin(角度)      ← sin 管"纵向"
```

相邻两个 logo 之间间隔 360° ÷ 12 = 30°，所以 12 个 logo 刚好均匀铺满一整圈。

## 无缝循环的秘密 ⚡

这是本项目最关键的参数设计，三个数必须**乘起来恰好等于 360**：

| 参数 | 值 | 含义 |
|------|-----|------|
| `FRAMES` | 72 | 一共有 72 帧 |
| `ROTATION_SPEED` | 5 | 每帧整体旋转 5° |
| 72 × 5 | **= 360°** | 播完正好转满一整圈 |

> 只要 `帧数 × 每帧角度 = 360`，最后一帧的下一帧就是第一帧本身，循环永远无缝。
> 想改转速也行，比如 90 帧 × 4°、60 帧 × 6°，都满足条件。

## 快速开始

### 1. 安装依赖

只需要两个库：

```bash
pip install pillow
```

### 2. 运行

```bash
python ksm.py
```

运行后在目录里就会看到生成好的 `bandori_gif.gif`。

### 3. 换成自己的图片（可选）

- **换中间的头像**：替换 `ksm.jpg` 即可
- **换/加团徽**：把图片放进 `compressed/`，命名为 `logo1.png`、`logo2.png`……然后修改 `ksm.py` 顶部的 `NUM_LOGOS = 12` 改成你的数量
- **注意**：改了 `NUM_LOGOS` 之后，请保持 `FRAMES × ROTATION_SPEED = 360` 不变，否则循环会"跳一下"接不上

## 可以玩的参数

都在 `ksm.py` 开头，随便改：

| 参数 | 默认值 | 效果 |
|------|--------|------|
| `BACKGROUND_COLOR` | 淡紫色 | 背景颜色 |
| `LOGO_WIDTH` | 120 | 团徽宽度（高度按原图比例自动算，不会把 logo 压扁） |
| `NUM_LOGOS` | 12 | 团徽数量 |
| `RADIUS` | 300 | 团徽离中心的距离，越大圈越大 |
| `ROTATION_SPEED` | 5 | 每帧转几度，越大转得越快 |
| `FRAMES` | 72 | 总帧数 |
| `duration=50` | 50 ms | 每帧停留时间，越小越流畅 |

## 一个小坑（踩过的经验 💡）

旧版代码把所有 logo 强制缩放成固定的 100×41，结果新加的 logo11（1080×300）、logo12（1200×420）被**压得又扁又变形**。新版改成了「**只固定宽度，高度按原图比例自动算**」，所有 logo 不管原始尺寸多大，都能保持原样不变形。
